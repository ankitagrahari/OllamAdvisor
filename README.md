## Ollama Advisor 
is a web application that advises on which model to use based on your system configuration, the work load, what kind of applications you use, and considering all the factors, it will provide the best model for your use case.

## Features
- Simple and easy to use interface 
- Show recommendations for models to use 
- Show best usecases for models
- Advises on fine tuning model confgurations
- Any environment variable change is also suggested

## Tech Stack
- React
- Tailwind CSS

## How to run

### Docker Compose
- Run `docker-compose up -d` to start the development server. It will run on port 5173.
- Run `docker-compose down` to stop the development server.

### NPM
- Run `npm run dev` to start the development server. It will run on port 5173.
- Run `npm run build` to build the production version. It will create a `dist` folder.
- Run `npm run preview` to preview the production build. It will run on port 5173.

## Access
- Open [http://localhost:5173](http://localhost:5173) to view it in your browser.
